Writing Effective Test Harnesses

          
The Test Harness gives FixPilot an objective target. Write standard Python assertions that exercise the fixed function:

          
def test_my_function():
    result = my_function([1, 2, 3])
    assert result == 3, f"Expected 3, got {result}"

          
FixPilot executes this test inside its isolated execution sandbox. If the fix fails, it loops back with the new error message (up to 3 iterations) until all assertions pass.
